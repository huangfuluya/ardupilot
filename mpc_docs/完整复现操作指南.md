# 完整复现操作指南

**目标**: 从零开始在ArduPilot SITL上复现 Chen et al. 2024 统一MPC控制器  
**适用平台**: Ubuntu 20.04 / 22.04 LTS  
**预计耗时**: 初次环境搭建约60分钟，后续编译+仿真约15分钟

---

## 第一步：环境搭建

### 1.1 安装系统依赖

```bash
sudo apt-get update
sudo apt-get install -y \
    git python3-pip python3-setuptools python3-dev \
    build-essential ccache g++ gdb \
    libtool libxml2-dev libxslt1-dev \
    python3-numpy python3-matplotlib \
    screen mavproxy
```

### 1.2 安装Python依赖

```bash
python3 -m pip install --user \
    empy==3.3.4 \
    pexpect \
    pymavlink \
    future \
    dronecan
```

### 1.3 安装MAVProxy（飞控地面站）

```bash
python3 -m pip install --user mavproxy
# 或
sudo apt-get install python3-mavproxy
```

## 第二步：获取代码

### 2.1 克隆仓库

```bash
# 完整克隆（含子模块，推荐）
git clone --recurse-submodules \
    https://github.com/huangfuluya/ardupilot.git \
    ardupilot-mpc
cd ardupilot-mpc

# 切换到MPC实现分支
git checkout copilot/implement-paper-replication
```

### 2.2 如果子模块未完整初始化

```bash
# 初始化关键子模块（按需执行）
git submodule update --init modules/waf
git submodule update --init modules/littlefs
git submodule update --init modules/DroneCAN
git submodule update --init modules/lwip
git submodule update --init modules/mavlink
# 可选：初始化所有子模块（耗时较长）
git submodule update --init --recursive
```

## 第三步：编译ArduPlane固件

### 3.1 配置SITL目标

```bash

cd ardupilot-mpc

# 配置SITL板型
```

预期输出末行:

```bash
ls build/sitl/libraries/AP_VTOL_MPC/

```

## 第四步：基础飞行测试（不启用MPC）

### 4.1 启动SITL仿真

```bash
# 在一个终端中启动仿真（tilthvec机型）
Tools/autotest/sim_vehicle.py \
    -v ArduPlane \
    -f tilthvec \
    --console --map \
    --add-param-file=Tools/autotest/default_params/tilthvec.parm
```

### 4.2 首次飞行前确认参数

在MAVProxy控制台中输入：

```
# 确认tilthvec关键参数
param show Q_ENABLE
param show Q_TILT_ENABLE
param show Q_FRAME_CLASS
# 确认MPC默认未启用
param show Q_MPC_ENABLE  # 应为0
```

### 4.3 基础VTOL悬停测试

```
mode QHOVER
arm throttle
rc 3 1600
# 等待上升到约10m
rc 3 1500
# 悬停10秒，确认稳定
disarm
```

## 第五步：启用MPC控制器

### 5.1 设置MPC参数

```
# 启用MPC（需要之后重启才完全生效，但SITL可直接生效）
param set Q_MPC_ENABLE 1

# 标准配置（对应论文参数）
param set Q_MPC_DT_MS 20
param set Q_MPC_HORIZON 20
param set Q_MPC_QVX 20
param set Q_MPC_QVY 10
param set Q_MPC_QVZ 50
param set Q_MPC_QROLL 10
param set Q_MPC_QPITCH 20
param set Q_MPC_IQITR 20
```

### 5.2 保存参数到文件（可选）

```bash
# 在MAVProxy中
param save /tmp/mpc_params.parm
```

## 第六步：MPC控制器仿真验证

### 6.1 悬停稳定性验证

```
# 在MAVProxy中
arm throttle
mode QHOVER
rc 3 1600
# 等待上升
rc 3 1500
# 监控GCS输出，应看到:
# "AP_VTOL_MPC: MPC controller initialised (Chen 2024)"
# 悬停30秒观察
```

**预期日志输出**:
- `ATT.Roll` < 5°，`ATT.Pitch` < 5°
- `TILT.current_tilt` ≈ 0（悬停时倾转角接近0）
- 无 "MPC fallback" 相关日志

### 6.2 倾转过渡验证

```
mode QRTL  # 触发返航，包含从悬停到前飞的过渡
# 或
mode FBWA  # 固定翼模式，触发tiltrotor transition
```

**观察要点**:
- `TILT.current_tilt` 从0平滑增加到1（0°→90°）
- `ATT.Pitch` 从0°逐渐增加到约5°（建立前飞俯仰）
- 高度 `GPS.Alt` 变化 < 2m
- 全程无模式切换提示（MPC单一代码路径）

### 6.3 AUTO航线任务验证

```bash
# 加载tilthvec标准航点任务
wp load Tools/autotest/Generic_Missions/tilthvec.waypoints

# 启动自主任务
mode AUTO
```

**航线内容**（典型tilthvec任务）:
1. VTOL起飞至10m
2. 前往第一个航点（触发前飞过渡）
3. 巡航飞行
4. 返回起始点（触发减速过渡）
5. VTOL降落

**监控命令（MAVProxy）**:
```
status
graph ATT.Roll ATT.Pitch
graph TILT.current_tilt
```

```bash
# 检查倾转角变化
mavlogdump logs/00000001.BIN --type TILT | grep "current_tilt"
```

## 第八步：参数调优（如需）

### 8.1 高度通道调优

如果高度跟踪不稳定（振荡）：
```
# 增加高度权重
param set Q_MPC_QVZ 70
# 或减少预测时域（减少超调）
param set Q_MPC_HORIZON 15
```

### 8.2 过渡段调优

如果倾转过渡过慢或过快：
```
# 调整倾转角速率约束（通过修改源码 chi_dot_max）
# 或调整推力权重（影响推力调度）
param set Q_MPC_QVZ 40  # 适当降低高度惩罚允许更大俯仰前倾
```

### 8.3 前飞稳定性调优

如果高速前飞俯仰振荡：
```
param set Q_MPC_QPITCH 30  # 增加俯仰角惩罚
param set Q_MPC_IQITR 30   # 增加优化迭代次数
```

## 常见问题排查

### Q: 编译失败，找不到子模块

```bash
git submodule update --init --recursive
```

### Q: 仿真启动时报 "empy not found"

```bash
python3 -m pip install empy==3.3.4
```

### Q: MAVProxy看不到MPC初始化消息

确认 `Q_MPC_ENABLE=1` 且 `Q_ENABLE=1`，重新arm后进入QHOVER模式。

### Q: MPC启用后飞行不稳定

先禁用MPC（`param set Q_MPC_ENABLE 0`），以标准PID飞行，确认内环参数（`Q_A_ANG_RLL_P`, `Q_A_RAT_*`等）正常后再重新启用。

### Q: 过渡段高度大幅下降

增加 `Q_MPC_QVZ` 到60~80，同时适当减小 `Q_MPC_QPITCH`（减少俯仰前倾偏置）。
