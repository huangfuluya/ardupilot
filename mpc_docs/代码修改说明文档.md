### 3.2 新库 AP_VTOL_MPC 各模块说明

#### 3.2.1 VTOLDynamics — 倾转旋翼非线性动力学模型

实现论文方程(1)~(23)的全飞行包线动力学模型：

- **状态向量** (n=14):
  ```
  x = [vN, vE, vD, χ_L, χ_R, φ, θ, ψ, p, q, r, p⁻, q⁻, r⁻]
  ```
  - `vN/vE/vD`: 惯性系NED速度 [m/s]
  - `χ_L/χ_R`: 左/右侧倾转角 [rad]（0=悬停朝上, π/2=前飞朝前）
  - `φ/θ/ψ`: 欧拉角 (滚转/俯仰/偏航) [rad]
  - `p/q/r`: 机体角速率 [rad/s]
  - `p⁻/q⁻/r⁻`: 上一步角速率（用于内环微分项模型）

- **控制输入向量** (m=6):
  ```
  u = [χ̇_L, χ̇_R, T, φ_d, θ_d, ψ_d]
  ```
  - `χ̇_L/χ̇_R`: 倾转角速率指令 [rad/s]（约束 ±π/4）
  - `T`: 总推力 [N]（论文单一推力变量）
  - `φ_d/θ_d/ψ_d`: 内环姿态期望值 [rad]

- **关键模型特性**:
  - 旋翼推力方向: `[sin(χ), 0, -cos(χ)]`（机体坐标系，对应论文方程2~3）
  - 气动力: 基于升力/阻力线性化，含气动有效性因子 `e(Va)`（论文图4）
  - 内环PD力矩模型: 与ArduPilot AC_AttitudeControl一致（论文方程21~22）
  - 雅可比矩阵: 数值中心差分（用于梯度后向传递）

#### 3.2.2 MPCSolver — 滚动时域优化求解器

实现论文第III.B节的滚动时域优化，采用**一阶投影梯度下降**（替代论文中的CasADi NLP，适用于嵌入式实时求解）：

**代价函数（论文方程17~20）**:

$$J = \sum_{k=0}^{N-1} L_k(x_k, u_k) + J_f(x_N)$$

- **速度跟踪项** $J_{ref}$（论文式18）:
  $$J_{ref} = (v - v_{ref})^T Q_{ref} (v - v_{ref})$$
  $Q_{ref} = \text{diag}(20, 10, 50)$（论文表2）

- **姿态/角速率项**（论文式19）:
  $$J_{att} = \Psi^T Q_\Psi \Psi + \dot{\Psi}^T Q_{\dot\Psi} \dot\Psi + u^T R_u u$$
  $Q_\Psi = \text{diag}(10, 20, 10)$，$R_u = \text{diag}(1,1,0.025,10,20,10)$

- **软约束项**（论文式20）:
  $$J_{soft} = e^{a \cdot V_{fwd} \cdot \chi/90° + b \cdot \chi/90° + c \cdot V_{fwd}/30 + d}$$
  参数 $a=-0.33, b=13.32, c=1.80, d=-2.303$

**求解算法**:
1. 暖启动：将上一步解向前移位一步
2. 前向传递：用非线性动力学传播状态轨迹
3. 后向传递（伴随法）：计算梯度 $\nabla_U J$
4. 投影梯度步 + Armijo线搜索
5. 重复20步迭代（约1ms计算时间@SITL）

**约束处理（论文方程16）**:

| 约束变量 | 下界 | 上界 |
|---------|------|------|
| 倾转角 χ | -7° | 95° |
| 倾转角速率 χ̇ | -π/4 rad/s | π/4 rad/s |
| 总推力 T | 0 N | 109.4 N |
| 期望俯仰 θ_d | -60° | 60° |
| 期望滚转 φ_d | -90° | 90° |

#### 3.2.3 ControlAllocator — 控制分配（论文第III.C节）

基于效能矩阵的最优控制分配，将MPC输出的期望力/力矩映射到各执行机构：

- **效能矩阵** A (6×5): 将执行机构增量 $\Delta u$ 映射到合力/合力矩增量 $\Delta W$
- **执行机构**: 左侧电机(归一化转速²)、右侧电机、副翼、升降舵、方向舵
- **优化**: $\min \|A\Delta u - \Delta W\|^2$ subject to 各执行机构边界约束
- **求解**: 对角预条件化投影梯度法（30步迭代）

### 3.3 ArduPilot集成策略

**设计原则**: MPC完全替换速度外环，保留ArduPilot的姿态内环PID（符合论文双环架构）

**集成点**:

1. **hold_hover()** (悬停模式):
   - 若 `Q_MPC_ENABLE=1`，调用 `run_mpc_velocity_controller(vel_ref, yaw_ref)`
   - 成功则直接返回，跳过原PID路径
   - 失败则fallback到原ArduPilot PID控制

2. **vtol_position_controller()** (VTOL位置控制):
   - 若MPC启用，在switch-case前先尝试MPC
   - MPC成功则直接return，保留原switch-case用于MPC失败回退

3. **mode_enter()** (飞行模式切换):
   - 设置 `mpc_reset_needed = true`
   - 确保每次进入新模式时MPC轨迹重新初始化

4. **setup()** (系统初始化):
   - 调用 `vtol_mpc.init()` 完成对象分配和参数初始化

## 四、核心参数列表

所有参数均以 `Q_MPC_` 为前缀（对应ArduPilot参数命名规范）：

| 参数名 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| `Q_MPC_ENABLE` | 0 | 0/1 | 启用MPC控制器（需重启）|
| `Q_MPC_HORIZON` | 20 | 5~20 | 预测时域步数（论文25步） |
| `Q_MPC_DT_MS` | 20 | 10~50 | MPC时间步长（ms），对应50Hz |
| `Q_MPC_QVX` | 20.0 | 1~200 | 北向速度跟踪权重 |
| `Q_MPC_QVY` | 10.0 | 1~200 | 东向速度跟踪权重 |
| `Q_MPC_QVZ` | 50.0 | 1~200 | 高度速度跟踪权重 |
| `Q_MPC_QROLL` | 10.0 | 1~200 | 滚转角代价权重 |
| `Q_MPC_QPITCH` | 20.0 | 1~200 | 俯仰角代价权重 |
| `Q_MPC_IQITR` | 20 | 5~50 | 梯度迭代次数 |

## 六、注意事项

1. **首次启用MPC前**：建议先以 `Q_MPC_ENABLE=0` 在SITL中验证基础飞行，确认tilthvec机型参数（Q_FRAME_CLASS=1, Q_FRAME_TYPE=3等）正确。

2. **MPC参数整定顺序**：先调 `Q_MPC_QVZ`（高度通道稳定最关键），再调 `Q_MPC_QVX/QVY`（水平速度跟踪），最后根据瞬态表现调整 `Q_MPC_HORIZON` 和 `Q_MPC_IQITR`。

3. **failsafe机制**：若MPC求解返回false（如AHRS速度估计失效），自动回退到标准PID控制，无缝切换，保证飞行安全。

4. **tilthvec适配说明**：原论文使用4个独立倾转舵机，tilthvec SITL模型仅有2个（k_tiltMotorLeft/k_tiltMotorRight）。实现中将左右独立控制，两侧取平均后写入对称倾转舵机，此为工程适配，对MPC核心优化逻辑无影响。
